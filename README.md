# 🎬 Ghibli Checklist

Um checklist interativo para acompanhar quais filmes do **Studio Ghibli** você já assistiu, organizado cronologicamente por ano de lançamento (1984–2023).

🔗 **[Ver demo ao vivo](https://mayannara.github.io/ghibli-checklist/)**

![Status](https://img.shields.io/badge/status-completo-brightgreen)
![License](https://img.shields.io/badge/license-MIT-blue)

## 📋 Sobre o projeto

Este projeto nasceu da vontade de ter uma forma visual e interativa de acompanhar a jornada pela filmografia completa do Studio Ghibli — um dos estúdios de animação mais aclamados do mundo. A aplicação lista os 22 longas-metragens do estúdio, com diretor e curiosidades de cada um, permitindo marcar os já assistidos.

## ✨ Funcionalidades

- ✅ Checkboxes interativos para marcar filmes assistidos
- 📊 Estatísticas de progresso em tempo real (quantidade e percentual)
- 💾 Persistência local via `localStorage` — o progresso não se perde ao fechar o navegador
- 📱 Layout responsivo (desktop, tablet e mobile)
- 🖨️ Estilos otimizados para impressão
- 🎨 Design com paleta de cores inspirada na estética Ghibli

## 🛠️ Tecnologias utilizadas

- **HTML5**
- **CSS3** (Grid, Flexbox, animações e gradientes)
- **JavaScript** (vanilla, sem frameworks ou dependências externas)

## 🚀 Como rodar localmente

Não é necessário nenhum processo de build ou instalação de dependências:

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/ghibli-checklist.git

# Entre na pasta
cd ghibli-checklist

# Abra o index.html no navegador
```

Ou simplesmente abra o arquivo `index.html` diretamente no navegador.
